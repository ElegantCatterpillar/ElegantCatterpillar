## About

I started as a mechatronics engineer automating industrial processes, then moved into software and stayed there. For 10+ years I've built systems for industry: web, desktop and mobile apps, the APIs behind them, and lately the AI that makes them smarter. I also lead a small dev team, so code reviews and mentoring are part of the job.

## What I build

- **Custom systems**: web and mobile platforms to run, control and measure critical processes, including offline-first apps for the field.
- **AI integration**: assistants, automation and search over your own data, wired into the tools you already use.
- **Technical consulting**: architecture, code reviews and hands-on guidance so a team ships with confidence.

## Highlights

- Started the software department at an engineering firm and grew it from one person to a working team.
- Built 30+ internal apps at an aerospace plant, including turning a paper-based technical documentation process into a fully digital one.
- Shipped complete systems end to end: desktop services, web and mobile apps, and device integrations for monitoring and reporting.
- Integrated LLMs into existing production systems.
