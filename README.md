### About

I'm a full-stack developer with 10+ years of experience. I started as a mechatronics engineer automating industrial processes, then moved into software and stayed there.

These days I build web, desktop and mobile apps, REST APIs, and the infrastructure behind them. I also lead a small dev team — mentoring, code reviews, and the usual herding of cats. Mostly working in the .NET and Vue ecosystems.

I like problems that are a bit annoying to solve. Currently open to remote work.

### A few things I've done

- Started the software department at an engineering firm and grew it from one person to a working team.
- Built 30+ internal apps in an aerospace plant, including turning a paper-based technical documentation process into a fully digital one.
- Shipped full systems end to end — desktop services, web apps, mobile apps, and device integrations for monitoring and reporting.
- Done a fair amount of AI/automation work lately, mostly integrating LLMs into existing systems.
